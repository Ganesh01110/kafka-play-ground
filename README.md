# Backend Playground Monorepo

This repository consolidates multiple backend technology playground projects, each exploring different messaging and caching systems.

## 📁 Projects

### 1. [Kafka Play Ground](./kafka-play-ground)
A hands-on exploration of Apache Kafka for distributed event streaming and message processing.

**Technologies**: Apache Kafka, KafkaJS, Node.js, Docker, Zookeeper

**Key Features**:
- Producer-consumer pattern implementation
- Multiple consumer groups
- Docker-based Kafka and Zookeeper setup

[📖 View Full Documentation](./kafka-play-ground/readme.md)

---

### 2. [Redis Play Ground](./redis-play-ground)
Experiments with Redis for caching, data structures, and performance optimization.

**Technologies**: Redis Stack, ioredis, Node.js, Express, Docker

**Key Features**:
- Redis caching implementation
- Performance comparison with/without caching
- Redis Stack with RedisInsight UI
- Integration with REST APIs

[📖 View Full Documentation](./redis-play-ground/README.md)

---

### 3. [Redis PubSub Queue in Node.js](./redis_pubsub-queue_in_nodejs)
Implementation of publish-subscribe patterns and message queuing using Redis.

**Technologies**: Redis, Node.js, Pub/Sub Pattern

**Key Features**:
- Publisher-subscriber messaging
- Queue-based message processing
- Real-time event distribution

[📖 View Full Documentation](./redis_pubsub-queue_in_nodejs/README.md)

---

## 🎯 Purpose

This monorepo serves as a learning playground for backend messaging and caching technologies. Each sub-project maintains its own commit history and can be explored independently.

## 🚀 Getting Started

Navigate to any sub-project directory and follow its specific README for setup instructions.
